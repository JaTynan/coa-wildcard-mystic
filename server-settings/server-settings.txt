# James's server settings, re-applied by Apply-Settings.cmd

# Each line:  <config file> | <setting> = <value>
# The file is relative to C:\Games\CoA Server\Core\configs. Lines starting with # are ignored.
# A value of ? means "not recorded yet": Save-Current.cmd fills it in from what the server has now,
# and Apply-Settings.cmd skips it until then.
# Changes take effect when the server next starts (or .reload config for most of them).
