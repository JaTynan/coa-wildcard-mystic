Start playing in three steps

Full guide
  1. Make an account

    Use the invite code James gave you on the sign-up page.

  2. Install with the launcher

    Unzip it, run Start Wildcard. It downloads the game (about 45 GB).

  3. Press Play

    The launcher checks for updates each time, then starts the game.

Installing for the first time
  1. Unzip it into a new folder on a drive with about 100 GB free, for example C:\Games\Wildcard.
  2. Double-click Start Wildcard. If Windows asks whether to run it, choose Run (or More info, then Run anyway). That only happens the first time.
  3. The first time, it downloads the game (about 45 GB) and unpacks it. Leave it running; if it stops, just start it again and it carries on where it left off.
  4. When it says Up to date, press Play and log in with your account.

Tip: right-click Start Wildcard and choose Send to, Desktop (create shortcut). If something goes wrong, the launcher's Log button shows what happened; send that to James. Forgotten your password? Ask James.
