Wildcard

James's World of Warcraft server. Random abilities, Mystic Enchants, and a world full of bots.

Download the launcher

No account yet? Make one at join.jtlab.cc with the invite code James gave you. The download can run while you do.

  1. Unzip it into a new folder on a drive with about 100 GB free, for example C:\Games\Wildcard.
  2. Double-click Start Wildcard. If Windows asks whether to run it, choose Run (or More info, then Run anyway). That only happens the first time.
  3. The first time, it downloads the game (about 45 GB) and unpacks it. Leave it running; if it stops, just start it again and it carries on where it left off.
  4. When it says Up to date, press Play and log in with your account.

From then on, always start the game with Start Wildcard: it fetches any updates first, which only takes a moment. Tip: right-click it and choose Send to, Desktop (create shortcut).
