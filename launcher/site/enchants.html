What the statuses mean

Confirmed working
Tested in game and does what it says. Nothing has changed since.
Restored
It was broken and we fixed it; the fix is on the server. Not yet confirmed in game, so tell us how it goes.
Waiting on feedback
Should work: it worked as it came, or it passed a test before a later change. Nobody has confirmed it since.
Not working yet
Known not to work, or only partly. Some have a fix waiting for the next server update.

Found an enchant that does not do what it says, or one that works? Use Report Bug in game and name the enchant. Every report helps move an enchant to Confirmed working. Recent fixes are listed on the Changes page.
