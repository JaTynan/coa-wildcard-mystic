means no template lists the name, so see section 4. Where two upstream templates share a file name
(`mod_ahbot.conf.dist` ships with the core and with SQUID's bots) the value shown is from whichever was
read last; check the installed `.dist` on the VM before relying on an auction-bot default.

### 3b. Our option reads that sit directly inside a per-tick hook (7) - candidates, cost not measured

`OnPlayerUpdate` runs for every player object on every world tick, and each bot is a player object. A
`GetOption` there is a text look-up and a conversion per call. The repository names "a setting read on a hot
path without caching" as a common patch fault (docs/agents/context/patches.md). Found by the enclosing
function name only: a read reached through a helper (`Enabled()`, `Applies()`) is not listed, and a read
behind a cheap race or timer check runs far less often than the hook does. Nobody has measured what these
cost; treat the list as where to look, not as a finding.
